# Runtime Data

This directory is created and updated by the check-in dashboard at runtime.

Do not commit real files from this directory. They may contain account cookies,
site passwords, Telegram chat IDs, Telegram session strings, and check-in
history snapshots.

Expected runtime files include:

- `accounts.json`
- `embypulse_accounts.json`
- `embymb_accounts.json`
- `zhousanwan_accounts.json`
- `telegram-chat-id.txt`
- `telegram_bot_checkin_skip.json`
- `embykeeper/config.toml`
- `embykeeper/form.json`
- `embykeeper/runtime/*`
